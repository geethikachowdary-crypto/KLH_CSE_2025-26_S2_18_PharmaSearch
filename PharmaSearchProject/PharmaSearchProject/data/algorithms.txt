Knuth-Morris-Pratt, or KMP, is a string matching algorithm used in Pharma Search to search for a medicine name inside a larger block of text without rechecking characters unnecessarily. KMP builds a longest prefix suffix array, often called the LPS array, for the searched medicine name before scanning the medicine records. Using the LPS array, Pharma Search can skip unnecessary comparisons whenever a mismatch occurs while searching for a medicine name. Rabin-Karp is another algorithm considered in Pharma Search, and it uses hashing to compare a query against medicine records quickly. Edit Distance measures the minimum number of insertions, deletions, or substitutions required to transform one medicine name into another, which allows Pharma Search to perform fuzzy matching. Pharma Search applies these algorithms so that searches remain fast and accurate even as the pharmaceutical dataset grows in size.
